# 🚀 GeoPulse — Система локальной репутации и фильтрации негатива

Микро-SaaS решение для малого офлайн-бизнеса (кафе, салоны красоты, автосервисы, клиники). 
Перехватывает жалобы клиентов до того, как они попадут на Яндекс.Карты или 2ГИС, и направляет довольных гостей ставить 5 звезд.

---

## 📂 Структура проекта

```
projectveka/
├── app/
│   ├── templates/
│   │   ├── review.html      # Мобильный экран оценки для гостя
│   │   └── table_tent.html   # Макет тейбл-тента для печати на стол
│   ├── config.py             # Настройки заведений и Telegram
│   └── main.py               # Бэкенд FastAPI (роуты, QR-генератор, логика перехвата)
├── feedbacks.jsonl           # Локальная база перехваченных жалоб
├── run.py                    # Скрипт запуска сервера в 1 клик
├── requirements.txt          # Зависимости проекта
└── README.md
```

## ⚡ Быстрый старт (локальный запуск)

1. Откройте терминал в папке проекта и запустите:
   ```bash
   python run.py
   ```
2. Откройте в браузере:
   * **Панель управления:** [http://127.0.0.1:8000](http://127.0.0.1:8000)
   * **Экран гостя Кафе «Daikon»:** [http://127.0.0.1:8000/r/daikon](http://127.0.0.1:8000/r/daikon)
   * **Печать тейбл-тента:** [http://127.0.0.1:8000/print/daikon](http://127.0.0.1:8000/print/daikon)

## 📲 Как подключить Telegram-уведомления (за 2 минуты)

Чтобы перехваченный негатив мгновенно падал вам в мессенджер:

1. Откройте Telegram и найдите бота **@BotFather**.
2. Отправьте `/newbot`, укажите имя и юзернейм бота. Скопируйте полученный **токен бота**.
3. Найдите бота **@userinfobot** и нажмите `Start` — он покажет ваш персональный **Id** (число, например `74829104`).
4. Откройте файл `app/config.py` (или создайте `.env`) и укажите эти значения:
   ```python
   TELEGRAM_BOT_TOKEN = "ВАШ_ТОКЕН_ОТ_BOTFATHER"
   TELEGRAM_CHAT_ID = "ВАШ_CHAT_ID"
   ```
5. Нажмите `Start` в своем новом боте. Теперь при отправке жалобы бот моментально пришлет тревожный сигнал с контактами клиента!
