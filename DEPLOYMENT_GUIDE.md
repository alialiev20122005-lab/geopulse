# 🚀 Пошаговое руководство по деплою GeoPulse на VPS (TimeWeb Cloud)

Это руководство позволит вам развернуть проект на облачном сервере в России за 10 минут. 
Сервис и Telegram-бот будут работать 24/7/365, даже когда ваш компьютер выключен.

---

### Шаг 1. Аренда сервера на TimeWeb Cloud (~200–250 ₽/мес)

1. Зайдите на сайт [timeweb.cloud](https://timeweb.cloud/) и зарегистрируйтесь.
2. В панели управления нажмите **«Создать» ➔ «Облачный сервер»**.
3. Выберите параметры:
   * **Операционная система:** `Ubuntu 24.04` (или `22.04`).
   * **Регион:** `Москва` (или `Санкт-Петербург`).
   * **Конфигурация:** Самый минимальный тариф (например, `1 vCPU, 1–2 GB RAM, 20–30 GB NVMe`). Этого с головой хватит на первые 500 заведений.
   * **Оплата:** почасовая (~0.35 ₽/час или ~250 ₽/мес). Достаточно пополнить баланс на 100–200 рублей для старта.
4. Нажмите кнопку **«Заказать»**. Через 1–2 минуты сервер будет готов.
5. На вашу почту придут реквизиты доступа:
   * **IP-адрес сервера** (например: `185.123.45.67`)
   * **Пользователь:** `root`
   * **Пароль**

---

### Шаг 2. Подключение к серверу с вашего компьютера

Откройте командную строку PowerShell на вашем компьютере и введите:
```powershell
ssh root@ВАШ_IP_СЕРВЕРА
```
*(Пример: `ssh root@185.123.45.67`)*.
* На вопрос `Are you sure you want to continue connecting (yes/no)?` введите `yes` и нажмите Enter.
* Введите пароль от сервера (при вводе символы не отображаются — это нормально) и нажмите Enter.
Вы окажетесь внутри вашего облачного сервера!

---

### Шаг 3. Установка Docker и запуск GeoPulse (в 3 команды)

В терминале сервера выполните следующие команды:

1. **Скачайте и запустите авто-настройку Docker:**
   ```bash
   curl -fsSL https://get.docker.com -o get-docker.sh && sh get-docker.sh
   ```

2. **Создайте папку проекта и перейдите в нее:**
   ```bash
   mkdir -p /root/geopulse && cd /root/geopulse
   ```

3. **Скопируйте файлы проекта с вашего ПК на сервер (через SCP или Git):**
   *Быстрый способ с вашего компьютера (откройте второе окно PowerShell):*
   ```powershell
   scp -r c:\Users\Ali\Desktop\projectveka\* root@ВАШ_IP_СЕРВЕРА:/root/geopulse/
   ```

4. **Запустите проект на сервере в фоне:**
   ```bash
   cd /root/geopulse
   docker compose up -d --build
   ```

---

### Шаг 4. Проверка работы

После выполнения команды проект запущен 24/7!
* Откройте в браузере: `http://ВАШ_IP_СЕРВЕРА`
* Экран для гостей: `http://ВАШ_IP_СЕРВЕРА/r/daikon`
* Все Telegram-уведомления будут моментально приходить на ваш телефон круглосуточно.

---

### Шаг 5. Подключение своего домена (по желанию)

Когда вы купите домен (например, на Reg.ru или 2domains за 199 ₽):
1. В настройках DNS домена добавьте `A-запись`, указывающую на IP вашего сервера.
2. В файле `Caddyfile` на сервере замените `:80` на `вашдомен.ru`.
3. Перезапустите контейнеры: `docker compose restart caddy`.
Caddy автоматически и бесплатно выпустит SSL-сертификат (HTTPS)!
