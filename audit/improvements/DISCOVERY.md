# 🔍 GeoPulse Discovery & Architecture Analysis

## 1. Суть продукта и решаемая проблема

**GeoPulse** — это B2B SaaS-микроплатформа для ресторанного бизнеса, кафе, отелей, клиник и сферы услуг (HoReCa & Beauty), предназначенная для **проактивной защиты репутации заведений в геосервисах (Яндекс.Карты и 2ГИС)**.

### Ключевая проблема клиента (ресторатора / управляющего):
* 90% гостей стесняются высказать недовольство официанту в зале («Всё нормально»), но затем ставят 1–2 звезды на Яндекс.Картах из дома или такси.
* Удалить эмоциональный негатив через техподдержку Яндекса практически невозможно (требуются недели и доказательства).
* Падение рейтинга с 4.9 до 4.4 лишает заведение потока туристов и банкетных заказов (прямые потери от десятков до сотен тысяч рублей).

### Механика решения GeoPulse:
1. **Точка входа:** Гость сканирует QR-код со столика (`/r/{business_id}?table={number}`).
2. **Развилка (Smart Routing):**
   * **4–5 звёзд (Позитив):** Гость направляется в 1 клик на карточку заведения на Яндекс.Картах / 2ГИС для публикации открытого отзыва.
   * **1–3 звезды (Перехват негатива):** Отзыв не уходит в интернет. Гостю предлагается выбрать теги проблемы (остыло блюдо, долгая подача, грязный стол, грубость, ошибка в чеке) и оставить контакт.
3. **Мгновенный сигнал руководству:** За 1 секунду жалоба прилетает в Telegram директору точки с номером столика, контактом и готовым дипломатичным ответом от встроенного ИИ-помощника.
4. **Урегулирование на месте:** Управляющий подходит к столику в зале с комплиментом или пишет в WhatsApp, превращая недовольного гостя в постоянного клиента.

## 2. Архитектура и стек технологий

```mermaid
flowchart TD
    Guest["📱 Гость (QR со столика)"] -->|/r/{id}| FastAPIServer["⚡ FastAPI (Python 3.13 ASGI)"]
    Admin["👨‍💼 Администратор"] -->|/admin/*| FastAPIServer
    Manager["👔 Управляющий"] -->|/dashboard/{id}| FastAPIServer
    
    FastAPIServer -->|WAL Mode, Busy Timeout| SQLiteDB[("💾 SQLite 3 (geopulse.db)")]
    FastAPIServer -->|BackgroundTasks| TelegramAlert["🤖 Telegram Bot API (httpx)"]
    TelegramAlert -->|Уведомление за 1 сек| ManagerPhone["📱 Telegram Управляющего"]
    
    FastAPIServer -->|Fast Failover / Heuristics| AIAssistant["🧠 AI-помощник (OpenRouter / Эвристика)"]
    FastAPIServer -->|Atomic Backup 24h| BackupEngine["💾 Backup API (SQLite Online)"]
    BackupEngine -->|sendDocument| AdminTG["🛡️ Резервные копии в Telegram"]
    
    FastAPIServer -->|Init / Webhook| PaymentGateway["💳 ЮKassa / Счета / Sandbox"]
```

### Компоненты системы:
* **Backend:** FastAPI (Uvicorn ASGI), Python 3.13. 48 маршрутов (31 публичных/клиентских + 17 в роутере админ-панели).
* **База данных:** SQLite 3 в режиме `WAL` (Write-Ahead Logging) с `PRAGMA foreign_keys = ON`, `busy_timeout = 5000` и составными индексами. На хостинге Amvera хранится на постоянном томе `/data/geopulse.db`.
* **Frontend:** Jinja2 шаблоны (21 HTML-файл), адаптивная верстка на Tailwind CSS (скомпилированный `styles.min.css` 56 КБ + CDN fallback), чистый легковесный Vanilla JS без тяжелых фреймворков.
* **Telegram Bot:** Фоновый long-polling на `httpx.AsyncClient`, обрабатывающий `/start biz_{id}`, `/stats`, `/digest`, текстовый поиск точек и прямую привязку менеджеров.
* **Генерация QR-кодов:** Библиотека `qrcode` со стилизацией `StyledPilImage`, скругленными точками, фирменным градиентом и RAM-кэшем `_QR_MEMORY_CACHE` (ускорение до 1–2 мс).
* **AI-ассистент:** Модуль `app/ai_assistant.py` с быстрым отказоустойчивым переключением на эвристический генератор ресторанных ответов (5 категорий претензий).
* **Резервное копирование:** Атомарное создание копий через SQLite Online Backup API каждые 24 часа с авторотацией последних 7 файлов и отправкой `.db` в личный Telegram администратора.
* **Платежный контур:** Модуль `app/payments.py` (интеграция ЮKassa по 54-ФЗ с фискализацией, плюс тестовая песочница и выставление счетов).

## 3. Пользовательские сценарии (User Journeys)

### Сценарий 1: Гость в заведении (Критический путь)
1. Сканирует QR-код на столике → открывается `/r/{business_id}?table={num}` (скорость загрузки < 200 мс на мобильном 4G).
2. Выбирает звёзды:
   * 5★ → анимация благодарности, кнопка перехода на Яндекс.Карты.
   * 1–3★ → форма с 6 быстрыми чипсами проблем («Долго несли», «Остыло» и т.д.), поле комментария и контакт.
3. Нажатие «Отправить» → мгновенный ответ 200 OK, экран успеха, фоновая задача отправляет Telegram-алерт.

### Сценарий 2: Управляющий точкой
1. Подключается к боту по ссылке `t.me/my_geopulse_bot?start=biz_{id}` → аккаунт привязывается в `business_owners`.
2. При инциденте получает пуш в Telegram со ссылкой в WhatsApp гостю и ссылкой на дашборд.
3. Переходит в личный кабинет `/dashboard/{business_id}?auth={token}`:
   * Видит NPS (Net Promoter Score), средний балл, долю перехваченного негатива.
   * Управляет статусами жалоб (`new` → `resolved`).
   * Скачивает журнал отзывов в Excel (CSV с UTF-8 BOM).
   * Переходит в студию тейбл-тентов `/print/{business_id}/all` для допечатки карточек на столики.

### Сценарий 3: Администратор платформы (Владелец SaaS)
1. Авторизуется по `/admin/login` с сессионной защитой `HttpOnly` + `SameSite=Lax`.
2. В `/admin/businesses` добавляет новые заведения, настраивает ссылки на карты, статус подписки.
3. В `/admin/leads` ведет CRM заявок с сайта и коммерческого предложения, в 1 клик связывается в WhatsApp.
4. В `/admin/reviews` отслеживает общую ленту жалоб по всем заведениям сети/города.
5. Скачивает оперативный бэкап базы данных `.db` кнопкой в шапке.
