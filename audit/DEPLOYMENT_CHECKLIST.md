## 2. Инструкция по Обслуживанию и Перезапуску

### Запуск локально для разработки:
```powershell
python run.py
```
Сервис запустится на `http://127.0.0.1:8000`.

### Запуск полного автотест-сьюта:
```powershell
python test_audit_suite.py
```

### Деплой обновлений на сервер Amvera:
```powershell
git add .
git commit -m "feat/fix: описание изменений"
git push origin main
git push amvera main:master --force
git push amvera main --force
```

### Создание резервной копии базы данных вручную:
```powershell
python -c "import shutil, datetime; shutil.copy2('geopulse.db', f'backup_geopulse_{datetime.date.today()}.db'); print('Backup created successfully')"
```
